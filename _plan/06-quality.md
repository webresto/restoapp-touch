## Экраны и их пары в прототипе

| Экран клиента | Кто рисует | Прототип |
|---|---|---|
| Приветствие, вход, подключение, «Подключено» | хост | `welcome`, `signin`, `connect` |
| Заказы, заказ | рендер (+ P6 доска) | `r-orders`, `r-order` |
| Касса: чеки, чек, каталог, состав | натив `pos` | `r-pos`, `r-pos-receipt`, `r-pos-catalog` |
| Блюда, блюдо | рендер | `r-dishes`, `r-dish` |
| Клиенты, клиент | рендер | `r-clients`, `r-client` |
| Маркетинг: сводка, акции, акция, коды, код, применения | рендер (+ P5, P7) | `r-marketing`, `r-promotions`, `r-promotion`, `r-codes`, `r-code`, `r-applications` |
| Редактор акции | натив `marketing` | `r-promotion-edit` |
| Ассистент | натив `assistant` | `r-assistant` |
| Программы, маркетплейс, программа | рендер + натив `system` | `r-programs`, `r-market`, `r-program` |
| Настройки сервера | рендер + натив `settings` | `r-settings` |
| Каналы продаж | рендер | `r-channels` |
| Облако: серверы, сервер, баланс, операции | рендер (+ P7) | `services`, `service-*`, `balance` |
| Settings хоста (акцент, тема, язык) | Superizer | `settings` (часть) |

обзор облака (`home`), токены API облака (`tokens`), ⌘K-поиск.
