# Переход RestoApp touch на новый интерфейс

> План исполнения, 2026-11-18. Оценка, из которой он вырос, и решения владельца —
> `../.ai-notes/ui-port.plan.md` (В1–В6, А1–А2). Образец того, как должно выглядеть, —
> прототип `../../prototype-rikka/cloudApp` (коммит `a88827e`) и его скриншоты
> `../../prototype-rikka/screenshots/cloud/{compact,medium,expanded}/`. Правила экранов —
> `../../superizer/docs/13-ui-guidelines.md` (ветка `docs/ui-kit-guide`).

## Цель

Все экраны RestoApp touch — на новом интерфейсе прототипа, на телефоне, планшете и десктопе, в
светлой и тёмной теме, **с той же логикой, что сейчас**: меняется вид, а не протокол поведения.
Другие хосты Superizer (Unitool, app-learn, touch-vn) при этом не меняются.

## Что уже решено (не пересматривать)

| | Решение |
|---|---|
| Навигация между приложениями | выдвижное меню Superizer; на широком окне — рельс / боковая панель (`ShellLayout.Adaptive`) |
| Нижняя панель (В1) | только **внутри** приложения — его разделы (`AppSections`); глобальной нет |
| «Главная» (В2) | пока плитки; при запуске — последний сервер и последнее приложение; сводка дня — потом |
| Точки (В3) | свои у каждого приложения и пользователя (настройки на сервере); выбор — в шапке приложения |
| Ширина (В4) | шире 480 dp — только приложения, объявившие `AppWidth.Adaptive` |
| Цвет (В5) | акцент выбирает пользователь в Settings; у RestoApp по умолчанию фиолетовый |
| Шапка на десктопе (А1) | у широкого приложения бара оболочки нет, заголовок и «назад» — в `PageHeader` |
| Запуск (А2) | закрытое «назад» на Главную не открывается снова |

Порядок: **1 → 2 → 3** — после этого все объявленные сервером приложения уже в новом виде, без
изменений на серверах (первый видимый результат, ~12–16 дней). Затем **5 (касса первой)** и **4**
параллельно — они не зависят друг от друга; **6** идёт с каждым этапом и закрывает всё.

```
1 superizer ──► 2 host ──► 3 render ──┬──► 4 protocol (клиент + 2 сервера) ──┐
                                      └──► 5 native (касса → акция → …) ─────┴──► 6 релиз
```

## Готово, когда

1. Каждый экран прототипа имеет живую пару (таблица экранов — в `06-quality.md`) и сверен по
   скриншотам в трёх ширинах и двух темах.
2. Тесты клиента (`./gradlew desktopTest`), включая живые против restoapp-dev и облака, зелёные.
3. Старый сервер (без новых подсказок протокола) рисуется без ошибок — тем, что есть.
4. Unitool, app-learn, touch-vn собираются на Superizer 0.11.0 и их тесты зелёные.
5. TestFlight / APK собраны с CI.
