# 7. Экраны один в один с прототипом

Решение владельца (2026-11-18): экраны приложения должны соответствовать прототипу
`prototype-rikka/cloudApp`; хост и Superizer можно менять, меню — как в прототипе; сервер
(`/prj/restoapp-places`, ветка `dev-2.8`) можно расширять. Отменяет В1 (нет нижней панели) и В2 (Главная — потом).

## Правила

- Права — сервера. Блок стоит только с правом на его данные (ключа нет в ответе — блока нет, остальное
  смыкается), кнопка — только если метод есть в декларации, поле — только если пришло, навигация — только
  приложения пользователя. Новые данные сервер считает по тем же правам и только по доступной точке.
- Каждый экран проверяется снимками под тремя ролями демо (администратор, оператор, склад) в трёх ширинах.
- Сервер без новых данных (старый) не ломает клиент: нет приложения `home` — плитки, нет ключа — нет блока.

## Сделано (2026-11-19) — по комментариям к сравнению, и dev.resto.cloud

**Клиент и Superizer**
- Тёмная тема переносится между серверами, как язык (`RestoAppHost.connect(…, theme)`): у каждого сервера своё хранилище.
- Разделы приложения (`AppSections`) на телефоне — вкладки сверху, а не вторая нижняя панель.
- Рендерер: заголовок страницы всегда свой («Заказы»), строка под ним — `description` ответа списка; выбора точки в
  шапке приложения внутри оболочки больше нет (он в оболочке, `shell:point:item-<id>`). Список с доской на телефоне —
  карточки прототипа (полоса цвета этапа, время, клиент, `item.detail` с адресом, `item.note` «N поз.», сумма).
  Запись: главное действие широкой кнопкой и «⋯» с остальными (`<method>:more`), шаги пути по доске (`WayPanel`),
  состав заказа — строки с «2×», модификаторами и итогами (`summary list` + `totals`).
- Шкала столбчатых графиков — круглые шаги (`niceStep`).

**Сервер (`dev-2.8`, запушено)** — `where`, `itemsCount`, `itemsText`, `description` списка, `lines`/`totals` заказа,
ссылка на карточку клиента; у клиентов `spent`, `averageCheck`, `lastOrderAt`, последние заказы. Стенд:
`POST /__fake/demo` — день пиццерии (243 заказа, клиенты, промокоды). Модели мобильного API вне GraphQL витрины
(`graphql.public = false`): без этого сервер с GraphQL не поднимался. Образ `ghcr.io/webresto/restoapp:dev-2.8`
собирает CI (тестовый слой Dockerfile сохраняет `@webresto/*`, решатель капчи в тестах дополняет ключ до 32 байт).

**Облако** — в панели версия `dev-2.8`; плавающие теги тянутся `Always`. Сервис `touch-dev28` на dev.resto.cloud.
